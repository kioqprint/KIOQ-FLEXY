# KIOQ FLEXY

Android WebView launcher for the four flexy platforms, owned by KIOQ.STORE.

## Current starter scope
- Android application skeleton (Kotlin).
- Arabic/French app-language toggle (initial UI).
- WebView launch for configured platform URLs.
- GitHub Actions workflow that builds and uploads a debug APK artifact.

## Before production
- Confirm the official GIFTY and ONECLICK URLs.
- Confirm ALAADZ and FAWRIMOB URLs.
- Implement the agreed admin/customer backend, balances, debts, balance requests, and notifications.
- Add secure admin authentication and persistent customer data.
- Review each platform's WebView compatibility and terms.
- Configure a private repository if source privacy is required.

The current starter does not yet implement account management, financial records, balance synchronization, or push notifications. It does not use platform APIs.
